Module 1: Environment Setup

📋 What You'll Learn:

  • Install Java 21 (LTS version)
  • Install Maven build tool
  • Setup MySQL 8.0 database
  • Install IntelliJ IDEA Community Edition
  • Setup Supabase for cloud storage
  • Setup Mailtrap for email testing

⏱️ Time needed: 1-2 hours | Difficulty: Beginner

Why This Setup?

We're building a professional digital marketplace. Here's why we chose these technologies:

  • Java 21: Latest LTS with improved performance and modern features
  • Spring Boot 3.3.4: Industry-standard framework for Java web apps
  • MySQL: Reliable, scalable relational database
  • Supabase: Free cloud storage for product files (Blender models, textures)
  • Mailtrap: Safe email testing without sending to real addresses

Step 1: Install Java 21

Windows:

  1. Go to: https://www.oracle.com/java/technologies/downloads/#java21
  2. Download "Windows x64 Installer"
  3. Run the installer and follow prompts
  4. Add to PATH if not automatic

macOS:

brew install openjdk@21
sudo ln -sfn $(brew --prefix)/opt/openjdk@21/libexec/openjdk.jdk /Library/Java/JavaVirtualMachines/openjdk-21.jdk

Linux (Ubuntu/Debian):

sudo apt update
sudo apt install openjdk-21-jdk

Verify Installation:

java -version

Expected output: java version "21.0.x"

Step 2: Install Maven

Windows:

  1. Download from: https://maven.apache.org/download.cgi
  2. Extract ZIP to C:\Program Files\Apache\maven
  3. Add C:\Program Files\Apache\maven\bin to PATH

macOS:

brew install maven

Linux:

sudo apt install maven

Verify:

mvn -version

Step 3: Install MySQL 8.0

Windows/macOS:

  1. Download MySQL Community Server from: https://dev.mysql.com/downloads/mysql/
  2. Run installer
  3. IMPORTANT: Remember your root password!
  4. Choose "Use Strong Password Encryption"
  5. Start MySQL Server

Linux:

sudo apt update
sudo apt install mysql-server
sudo mysql_secure_installation

Create Database:

mysql -u root -p
CREATE DATABASE digital_marketplace;
SHOW DATABASES;
EXIT;

Step 4: Install IntelliJ IDEA

  1. Go to: https://www.jetbrains.com/idea/download/
  2. Download Community Edition (free)
  3. Install and launch
  4. Skip initial project setup for now

Step 5: Setup Supabase (Cloud Storage)

  1. Go to: https://supabase.com
  2. Sign up with GitHub (recommended) or email
  3. Click "New Project"
  4. Fill in:
    • Name: digital-marketplace
    • Database Password: Save this!
    • Region: Choose closest to you
  5. Wait for project creation (~2 minutes)
  6. Go to Storage → Create bucket:
    • Name: product-files
    • Public: ✅ Yes
  7. Create another bucket:
    • Name: product-images
    • Public: ✅ Yes
  8. Go to Settings → API → Copy:
    • Project URL
    • anon/public key
⚠️ SAVE YOUR CREDENTIALS: Store your Supabase URL and API key in a safe place. You'll need them in Module 25.

Step 6: Setup Mailtrap (Email Testing)

  1. Go to: https://mailtrap.io
  2. Sign up for free account
  3. In dashboard, click "Email Testing" → "Inboxes"
  4. Click "My Inbox" or create new inbox
  5. Click "SMTP Settings" → Select "Spring"
  6. Copy these values (you'll need them later):
    • Host: sandbox.smtp.mailtrap.io
    • Port: 2525
    • Username: (your username)
    • Password: (your password)

Understanding Spring Boot

Spring Boot is a framework that simplifies Java web development. It provides:

  • Auto-configuration: Smart defaults to get started quickly
  • Embedded server: No need to install Tomcat separately
  • Production-ready: Built-in health checks and monitoring
  • Convention over configuration: Less boilerplate code

Step 4: Configure application.properties

Navigate to: src/main/resources/application.properties

Replace content with:

# Server Configuration
server.port=8080

# Database Configuration
spring.datasource.url=jdbc:mysql://localhost:3306/digital_marketplace
spring.datasource.username=root
spring.datasource.password=YOUR_MYSQL_PASSWORD_HERE
spring.datasource.driver-class-name=com.mysql.cj.jdbc.Driver

# JPA/Hibernate Configuration
spring.jpa.hibernate.ddl-auto=update
spring.jpa.show-sql=true
spring.jpa.properties.hibernate.dialect=org.hibernate.dialect.MySQL8Dialect
spring.jpa.properties.hibernate.format_sql=true

# Thymeleaf Configuration
spring.thymeleaf.cache=false

# File Upload Configuration
spring.servlet.multipart.max-file-size=100MB
spring.servlet.multipart.max-request-size=100MB

# Logging
logging.level.org.springframework.security=DEBUG
logging.level.com.marketplace=DEBUG
⚠️ IMPORTANT: Replace YOUR_MYSQL_PASSWORD_HERE with your actual MySQL root password!

Understanding application.properties

  • spring.datasource.url - Database connection string
  • spring.jpa.hibernate.ddl-auto=update - Auto-create/update tables
  • spring.jpa.show-sql=true - Log SQL queries for debugging
  • spring.servlet.multipart.max-file-size=100MB - Allow large file uploads

Step 5: Create Your First Controller

Create package: src/main/java/com/marketplace/digital_marketplace/controllers

Create file: HomeController.java

package com.marketplace.digital_marketplace.controllers;

import org.springframework.stereotype.Controller;
import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.ResponseBody;

/**
 * HomeController handles requests to the home page
 */
@Controller
public class HomeController {
    
    /**
     * Handle GET requests to root URL "/"
     * @return Welcome message
     */
    @GetMapping("/")
    @ResponseBody
    public String home() {
        return "🎨 Welcome to Digital Art Marketplace! 🚀";
    }
    
    /**
     * Health check endpoint
     * @return Status message
     */
    @GetMapping("/health")
    @ResponseBody
    public String health() {
        return "✅ Application is running!";
    }
}

Understanding the Annotations

  • @Controller - Marks class as Spring MVC controller
  • @GetMapping("/") - Maps HTTP GET requests to method
  • @ResponseBody - Returns text directly (not a view name)

Step 6: Disable Security Temporarily

Create: src/main/java/com/marketplace/digital_marketplace/config/SecurityConfig.java

package com.marketplace.digital_marketplace.config;

import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;
import org.springframework.security.config.annotation.web.builders.HttpSecurity;
import org.springframework.security.config.annotation.web.configuration.EnableWebSecurity;
import org.springframework.security.web.SecurityFilterChain;

/**
 * Temporary security config - permits all requests
 * We'll configure proper security in Module 13
 */
@Configuration
@EnableWebSecurity
public class SecurityConfig {
    
    @Bean
    public SecurityFilterChain filterChain(HttpSecurity http) throws Exception {
        http
            .csrf(csrf -> csrf.disable())
            .authorizeHttpRequests(auth -> auth
                .anyRequest().permitAll()
            );
        return http.build();
    }
}

What is a Database?

A database stores information in organized tables (like Excel spreadsheets). Each table represents a type of data.

Key Database Concepts

Term Definition Example
Table Collection of related data "users" table stores all users
Row (Record) One piece of data One user: "john_doe"
Column (Field) One type of information "email" column
Primary Key Unique identifier (usually id) user_id = 1
Foreign Key Reference to another table product.seller_id → user.id

Our Database Tables (11 Total)

👤 1. users - User Accounts

Stores customer, seller, and admin information.

Column Type Description
id BIGINT (PK) Unique user ID
username VARCHAR(50) Login username (unique)
email VARCHAR(100) Email address (unique)
password VARCHAR(255) Encrypted password (BCrypt)
full_name VARCHAR(100) Display name
enabled BOOLEAN Account active? (default: true)
created_at DATETIME Registration timestamp

🔐 2. roles - User Roles

Defines permission levels: BUYER, SELLER, MODERATOR, ADMIN.

Column Type Description
id BIGINT (PK) Unique role ID
name VARCHAR(20) Role name (e.g., "ROLE_BUYER")

🔗 3. user_roles - Join Table

Links users to their roles (Many-to-Many relationship).

Column Type Description
user_id BIGINT (FK) References users.id
role_id BIGINT (FK) References roles.id

📁 4. categories - Product Categories

Organize products (3D Models, Textures, HDRIs, etc.).

Column Type Description
id BIGINT (PK) Unique category ID
name VARCHAR(50) Category name
description VARCHAR(255) Category description

🎨 5. products - Digital Assets

The main table storing product information.

Column Type Description
id BIGINT (PK) Unique product ID
name VARCHAR(100) Product name
description TEXT Detailed description
price DECIMAL(10,2) Price in dollars
file_url VARCHAR(500) Supabase download URL
approved BOOLEAN Moderator approved? (default: false)
download_count INT Times downloaded
seller_id BIGINT (FK) References users.id
category_id BIGINT (FK) References categories.id
created_at DATETIME Upload timestamp

🖼️ 6. images - Product Images

Multiple preview images per product.

Column Type Description
id BIGINT (PK) Unique image ID
path VARCHAR(500) Image URL from Supabase
is_primary BOOLEAN Main thumbnail? (default: false)
product_id BIGINT (FK) References products.id

⭐ 7. reviews - Product Reviews

Customer ratings and comments.

Column Type Description
id BIGINT (PK) Unique review ID
rating INT 1-5 stars
comment TEXT Review text
user_id BIGINT (FK) Who wrote the review
product_id BIGINT (FK) Which product
created_at DATETIME Review timestamp

🛒 8. cart_items - Shopping Cart

Items currently in user's cart (not yet purchased).

Column Type Description
id BIGINT (PK) Unique cart item ID
quantity INT Always 1 for digital products
user_id BIGINT (FK) Cart owner
product_id BIGINT (FK) Product in cart
added_at DATETIME When added to cart

📦 9. orders - Completed Purchases

Order history and payment tracking.

Column Type Description
id BIGINT (PK) Unique order ID
order_number VARCHAR(50) Human-readable order # (e.g., "ORD-2024-0001")
total_amount DECIMAL(10,2) Total price
status VARCHAR(20) PENDING, COMPLETED, CANCELLED
user_id BIGINT (FK) Buyer
created_at DATETIME Purchase timestamp

📄 10. order_items - Products in Order

Which products are in which order.

Column Type Description
id BIGINT (PK) Unique order item ID
price DECIMAL(10,2) Price at time of purchase
order_id BIGINT (FK) Which order
product_id BIGINT (FK) Which product

📝 11. seller_requests - Become a Seller

Users requesting seller privileges.

Column Type Description
id BIGINT (PK) Unique request ID
message TEXT Why they want to sell
status VARCHAR(20) PENDING, APPROVED, REJECTED
user_id BIGINT (FK) Requesting user
created_at DATETIME Request timestamp

Entity Relationships

users (1) ──────── (Many) products        [One seller has many products]
users (1) ──────── (Many) cart_items      [One user has many cart items]
users (1) ──────── (Many) orders          [One user has many orders]
users (1) ──────── (Many) reviews         [One user writes many reviews]
users (Many) ───── (Many) roles           [Many users have many roles]

products (1) ───── (Many) images          [One product has many images]
products (1) ───── (Many) reviews         [One product has many reviews]
products (1) ───── (Many) cart_items      [One product in many carts]
products (1) ───── (Many) order_items     [One product in many orders]
products (Many) ── (1) categories         [Many products in one category]

orders (1) ────── (Many) order_items     [One order has many items]

Why This Design?

  • Normalization: Data isn't duplicated (efficient storage)
  • Scalability: Easy to add new features
  • Integrity: Foreign keys prevent orphaned data
  • Flexibility: Users can have multiple roles

Sample Data Flow: Making a Purchase

  1. User browses products table
  2. Adds product to cart → creates cart_items record
  3. Clicks checkout → creates orders record
  4. System creates order_items for each cart item
  5. Cart items are deleted
  6. User can now download from order_items
💡 Note: Hibernate will auto-create these tables when you run the app (thanks to spring.jpa.hibernate.ddl-auto=update). No manual SQL needed!
